Para empezar, decidí organizar todo mi archivo CSS siguiendo exactamente el mismo orden visual en que aparecen las cosas en mi página HTML (comenzando por el header, después el main y finalmente el footer). Hice esto porque me resulta mucho más lógico y fácil de leer; si necesito cambiar un color o un margen, sé exactamente en qué parte del archivo buscar sin tener que saltar de un lado a otro.

Para la sección donde mostramos a los integrantes del equipo, decidí usar CSS Grid en lugar de Flexbox. Elegí Grid porque me permite armar una cuadrícula perfecta de columnas y filas de manera muy sencilla y directa. Si hubiera intentado hacer eso con Flexbox, controlar cómo se acomodan y bajan las tarjetas al pasar a la pantalla pequeña de un celular habría sido mucho más difícil y desordenado.

Por último, para lograr que el menú superior siga al usuario mientras lee la página, evalué un par de opciones para posicionarlo. If I had used position: fixed, the result would have been that all the text on the page jumps up abruptly, getting crowded and hidden underneath the menu. I chose position: sticky because it respects the original space that the header occupies, achieving the effect of accompanying the user while keeping the page completely clean and in order when scrolling down.
